# Aaditya Jha — Personal Website

Production-ready Next.js App Router portfolio focused on a minimal, editorial medical-student identity.

## Included
- Premium responsive design with separate CSS modules
- Animated page reveal and restrained motion
- Home, About, Projects, CHB project, Contact, Privacy and Terms
- SEO metadata per page
- Person structured data
- Sitemap and robots.txt
- AdSense + Google Analytics integration
- Vercel Analytics
- PWA web manifest
- Accessible navigation and semantic page structure

## Run
```bash
npm install
npm run dev
```
Then open http://localhost:3000.

## Production
```bash
npm run build
npm start
```

## Important
The site avoids inventing an email address or social profile URL that was not provided. Instagram is linked directly; LinkedIn and Facebook use name searches until exact profile URLs are supplied. The CHB project page is written without inventing research findings; original report/photos/data can be added later.
